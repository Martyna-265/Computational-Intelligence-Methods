# Computational Intelligence Methods in Data Analysis

Python projects made for the Computational Intelligence Methods in Data Analysis course during the sixth semester (2025/2026) at Warsaw University of Technology.

All projects were implemented in Python using libraries such as Pandas, NumPy and Torch.

---

## NN - Neuron Network

This project implements multilayer perceptrons (MLPs) with various modifications. The implementation was gradually extended to incorporate additional components. The effects of changes to network parameters were tested, and the network's performance was evaluated on multiple datasets covering both regression and classification tasks.

Implementing the algorithms from scratch enabled an in-depth analysis of the internal learning mechanisms, including optimization algorithms, various activation functions, and techniques for preventing overfitting.

---

## KOH - Kohonen Network

This project involved implementing Kohonen networks with rectangular and hexagonal neuron topologies for clustering and visualizing high-dimensional data. The effects of grid size, neighborhood width, and two neighborhood functions - Gaussian and Mexican hat - were investigated. The implemented algorithms were initially evaluated on simple synthetic spatial datasets and subsequently tested on more complex, real-world datasets.

---

## AE - Evolutionary Algorithm

This project involved implementing an evolutionary algorithm with various selection and mutation methods. The algorithm was applied to function maximization, the cutting stock problem, and weight optimization in a multilayer perceptron (MLP). Its effectiveness in solving these problems was evaluated, and the impact of different parameter settings on its performance was investigated.
